Rashid Editor - Phase 1
1. Android Studio (Koala 2024.1+ ya naya) mein File > Open > is folder (RashidEditor) ko select karein.
2. Gradle sync hone dein (internet chahiye, Gradle 8.9 khud download hoga).
3. Phone/emulator (API 26+) par Run karein.
4. APK: Build > Build Bundle(s) / APK(s) > Build APK(s).

--- APK bina Android Studio ke (GitHub se) ---
1. github.com par naya repository banayein (e.g. RashidEditor).
2. Is folder ki saari files (".github" folder samait) us repo mein upload karein.
3. Repo mein "Actions" tab kholein -> "Build APK" khud chal jayega (5-10 minute).
4. Green tick aane par us run ko kholein, neeche "Artifacts" mein
   "RashidEditor-APK" download karein. Zip khol kar app-debug.apk phone par install karein.
